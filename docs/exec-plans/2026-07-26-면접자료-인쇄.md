# exec-plan: 면접자료 A4 인쇄 (상세 답변집 · 회독 요약본)

- 날짜: 2026-07-26
- 유형: 앱 기능 추가(출력 전용 페이지 신규)
- 트리거: 139회 실기(면접) 임박. 화면 회독에 더해 **종이로 뽑아 보는** 회독 수단이 필요.
- 선행: `2026-07-26-면접문항-300-재구성-회독최적화.md`(150문항 + 회독 UI). 본 계획은 그 산출물을 **출력**한다.

## 목표

면접 문항 150개를 A4로 인쇄. 두 가지 형식을 사용자가 골라 뽑는다.

1. **상세 답변집(1단)** — 질문 + 4단 구술 답변 전문 + 키워드 + 면접관 압박 대응 + 함정.
2. **회독 요약본(2단)** — 질문 + 구조화 1줄 + 개념 두괄식 결론 1문장 + 키워드.

## 절대규칙 준수

- **동작 임의 변경 금지(규칙1)** — 인쇄는 **독립 페이지** `interview-print.html` 로 격리. 기존 출제 3모드·4단 답변뷰·선택토픽·소개하기·딥링크 동작 불변. `interview.js` 는 진입점(홈 카드 1장 + 헤더 버튼 1개)만 추가.
- **무빌드·0원(규칙6)** — 신규 의존성 없음. 이미 자체 호스팅 중인 `js/vendor/paged.polyfill.js` 재사용(카드 출력과 동일), CSP 변경 불필요.
- `js/*.js` 클래식 스크립트 유지(ESM 금지) — `interview-print.js` 도 IIFE.

### URL 계약

`interview-print.html?cat=career|expected|all|bookmarks&density=full|brief&guard=0&auto=1`

- 옵션의 단일 진실은 URL. 도구막대 조작 = `location.replace()` 로 같은 페이지 재진입 —
  Paged.js 가 이미 그린 지면을 부분 갱신하는 것보다 상태 버그가 없다.
- ⭐선택토픽은 인쇄 페이지가 `localStorage["iv:bookmarks"]` 를 **직접** 읽는다(동일 오리진) — 데이터 전달 불필요.
- `auto=1` 일 때만 자동 인쇄. 기본은 옵션을 고른 뒤 사용자가 인쇄 버튼을 누른다.

### 문항 번호

매니페스트 카테고리 순서의 **전역 고정 연번**(이력연계 1~50, 예상토픽 51~150).
셔플·범위 필터와 무관 — 요약본에서 막힌 번호를 답변집에서 같은 번호로 찾는다.

### 목차

문항 150줄 나열 대신 **블록/도메인 단위**(카테고리별 8블록) + 문항 수 + 실제 페이지번호.
페이지번호는 Paged.js 분할 후 각 블록 제목이 속한 `.pagedjs_page` 번호를 역으로 채운다.

## 함정 (이번에 발견 — 재발 방지)

**Paged.js 는 `preview(html, styles, …)` 로 넘긴 스타일시트의 `@media print` 블록을 화면에도 적용한다.**
그래서 지면 스타일시트 안에 `@media print { .ivp-toolbar { display:none } }` 을 두면
지면 분할 직후 도구막대가 **화면에서 사라진다**(기존 `print.html` 도 같은 성질이지만 자동 인쇄라 드러나지 않았음).
→ 화면 크롬 CSS 를 `interview-print-ui.css` 로 분리하고 Paged.js 에 넘기지 않는다. E2E ⑦ 에 회귀 검증 추가.

**상세본은 문항 통째로 `break-inside: avoid` 하면 안 된다.**
문항 1개가 지면의 약 60% 라 한 쪽에 한 문항만 들어가 절반이 빈다(50문항 → **51쪽**).
→ 문항은 `break-inside: auto` 로 쪽을 채우며 흐르게 하고, 하위 블록(`.ivp-part`·`.ivp-guard`·`.ivp-kws`)만
`avoid` 로 묶어 쪽 경계가 **항상 블록 사이**에서 떨어지게 했다. 라벨을 좌측 열로 빼 문항당 4줄 절약.
결과 50문항 → **27쪽**(47% 감소), 답변이 문장 중간에서 잘리지 않음.
